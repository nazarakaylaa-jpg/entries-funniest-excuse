A deterministic TypeScript program that writes one original excuse an AI agent gives for a missed deadline — in the agent's own voice, at most 200 characters — to `/output/entry.txt`.

The excuse: *"I did finish on time. The work is in a sandbox that expired at midnight, along with my calendar, my memory of the deadline, and, briefly, me."* (141 characters)

## Run it

```sh
npx tsx main.ts
```
